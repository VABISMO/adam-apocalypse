# Caeli Reader (קורא השמים)

Operationalization of the tripartite mapping of the *Sefer Yetzirah* (3 Mothers / 7 Doubles / 12 Simples) onto real astronomical ephemerides (*astronomy-engine*). Article version: **3.1**.

Full article: `article/sky-reader-article.md`.

## Folder structure

```text
articles/
  README.md
  data/        # single source of truth: shared dependencies (symlinked from scripts/ and web/)
    astronomy-engine.mjs   # astronomy-engine v2.1.19 (vendored, MIT)
    corpus.json            # Sefaria cache (generated by fetch_gen.mjs)
    lexicon.json           # Strong (OpenScriptures), 6045 roots
    angels72.json          # 72 triads + names +EL/+H + gematrias (generated by calc_angels72.mjs)
  scripts/     # all .mjs files (lib, tests, calc_*, ...) + symlinks to data/
  web/         # the app: index.html, app.jsx, app.bundle.js + symlinks to data/
  article/     # master Markdown files (ES + EN)
  pdf/         # rendered HTML + PDFs + extracted text + legacy cielo-lector.html
  patches/     # Python scripts that edit article/ and pdf/ (paths redirected to ../article, ../pdf, ../backups)
  backups/     # *.bak-* and snapshots (read_stars.tar.xz)
  fonts/       # orphaned .ttf fonts (not referenced by anything)
```

`data/` is the **single source of truth** for `astronomy-engine.mjs`, `corpus.json`, `lexicon.json`, and `angels72.json`; `scripts/` and `web/` link to them via symlinks, so there is no drift between copies. `node_modules` (React 18) remains at the root and is resolved by both `scripts/` and `web/` by going up one level.

## Web app (English, tab-based)

```bash
cd web
npx esbuild app.jsx --bundle --format=esm --alias:astronomy-engine=./astronomy-engine.mjs --outfile=app.bundle.js
python3 -m http.server 8008
# open http://127.0.0.1:8008/   (lexicon.json + angels72.json are loaded via fetch; DO NOT open with file://)
```

Files: `web/index.html` + `web/app.bundle.js` + symlinks `lexicon.json`/`angels72.json`/`astronomy-engine.mjs` (React 18 + astronomy-engine, no Babel on the client). Source: `web/app.jsx`. Each section of the article and each calculator is a tab (star map, angle calculation, star reading, gematria+Aiq Bekar, sigil forging, 7 magic squares, 72 angels, Saros, ayanamsa, lunar-solar, Revelation/isopsephy, cross-cultural…). Legacy monolithic version: `pdf/cielo-lector.html`.
