# Sefer Raziel HaMalakh — library/sefer-raziel

The Book of the Angel Raziel (Sefer Raziel HaMalakh), a Hebrew esoteric/cosmological
work (celestial letters, 22-letter gematria, 12 zodiacal letters, 72 names, 73 divine
names, 28 lunar mansions, planetary periods). This is the primary source the project
mined (see project memory: Raziel verified findings).

This folder is the canonical home of the Raziel source PDFs in the repository.

PDFs now live here verbatim (no download was performed — they are the project's
