# Source-text library — primary copies for the Caeli Reader Revelations research

Local copies of the primary source texts mined for the **Revelations** and
**Gematria** tabs. Each subfolder holds raw downloads (`.html`) and plain-text
extractions (`.txt`). These are reference copies only — page refs / URLs in the
app cite the original sources.

## Folders (273 plain-text files total)

- `nag-hammadi/` — Nag Hammadi Library (gnosis.org, 70 texts). Key:
  `adam.txt` (Apocalypse of Adam — 13 kingdoms + kingless generation = 14
  voices; the 13th: "every birth of their ruler is a word"), `apocjn.txt`
  (Apocryphon of John — 365 angels, 7, 12, powers/authorities/aeons),
  `origin.txt` (On the Origin of the World — 72 gods = 72 languages),
  `eugn.txt` (Eugnostos — 12→72→360 cascade), `egyp.txt` (Gospel of the
  Egyptians — 7 vowels × 22), `thunder.txt`, `trimorph.txt`, `hypastas.txt`.
  Corrections mined: 144/1260/42-month ABSENT from NH; "72 pentads" is a
  Pleše reconstruction (u).
- `avesta/` — Zoroastrian texts (avesta.org SBE). 51 files: 12 Yasna chapter
  groups (all 72 chapters), 16 Yashts (SBE), 22 Vendidad fargards. Key:
  `vendidad_vd1sbe` (16 sacred lands), `vendidad_vd2sbe` (Yima/Vara),
  `vendidad_vd22sbe` (99,999 diseases), `yasna_y28to34` (Ahunavaiti Gatha),
  the 7 Amesha Spentas, 21 Yashts, 72 Yasna chapters.
- `rig-veda/` — Rig Veda Samhita (Griffith tr., sacred-texts). 10 mandala
  indexes + 8 key cosmological hymns: `hymn_yearwheel_1-164` (12 fellies /
  360 spokes / 720 sons / 7 metres / 6+1 Ṛṣis), `hymn_adityas_10-72`
  (8 Adityas = 7 + Martanda), `hymn_surya_1-50` (7 bay steeds), `hymn_nasadiya_10-129`,
  `hymn_purusha_10-90`, `hymn_vac_10-125`, `hymn_visvakarman_1-73`, `hymn_agni_1-1`.
- `quran/` — Quran, Pickthall translation (sacred-texts), all 114 surahs
  (`surah_001.txt` … `surah_114.txt`). Key verses verified in-text:
  74:30 "nineteen", 36:39 "mansions" (moon), 9:36 "twelve months", 65:12
  "seven heavens + earth the like thereof", 15:87 "seven oft-repeated",
  67:3 "seven heavens in harmony".
- `sufi/` — pre-1500 Sufi/Islamic-esoteric scholarly reference pages (primary
  texts Futuhat/Rasa'il are not free online; these document them): Ibn Arabi
  Futuhat ch.198 (28 letters↔28 lunar mansions↔7 planets↔12 signs), Ikhwan
  al-Safa Epistle 22 (12 orifices / 28 vertebrae / 360 veins), Hurufiyya
  (28 Arabic + 32 Persian), Jawdan-name, Jafr, Ja'far esoteric sciences,
  Shams al-ma'arif al-kubra (pseudepigraphic — Gardiner/Coulon), abjad.
- `gematria/` — letter-number system reference pages (Wikipedia): Hebrew
  gematria + numerals (Mispar Hechrachi / Mispar Gadol / Mispar Katan
  Mispari), Greek isopsephy + numerals (digamma/koppa/sampi), Arabic abjad
  (Mashriqi + Maghrebi), Indian katapayadi (right-to-left), Āryabhaṭa
  numeration (positional), Cyrillic, Coptic (= Greek + Fai=90), Roman,
  Number of the Beast (666 = Neron Kesar Hebrew; 616 variant).

## Extraction notes
- All HTML stripped to UTF-8 plain text (tags removed, entities decoded,
  whitespace collapsed). Source `.html` kept alongside `.txt`.
- Nag Hammadi HTML was iso-8859-1; converted to UTF-8.
- Quran = Pickthall (public domain). Rig Veda = Griffith (public domain).
  Avesta = Sacred Books of the East (Darmesteter/Mills, public domain).
- Class tags used in the app: **(a)** verifiable astronomy · **(b)**
  eschatological/prophecy · **(c)** cosmological-doctrine · **(u)**
  unverified/late/pseudepigraphic.
- Boundary respected: Rig Veda Samhita vs Brahmana/Upanishadic; Gathas vs
  later Young Avestan/Pahlavi; Quran text vs hadith vs later Sufi doctrine.
