# library/hermetica — Corpus Hermeticum (G. R. S. Mead, 1906)

The **Hermetica** — the extant sermons and fragments of the Trismegistic literature
(the Corpus Hermeticum + Stobaeus excerpts + fragments), translated with prolegomena,
commentaries, and notes by G. R. S. Mead. This is the Hermetic corpus that frames Hermes
Trismegistus (a mage-ficha figure in this project) and the Hermetic / astrological-magical
lineage the magi index traces.
