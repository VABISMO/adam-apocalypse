# Ṛg Veda Saṃhitā — Griffith English translation

`rigveda_griffith_complete.txt` — the complete Griffith English translation of the
Ṛg Veda, all 10 maṇḍalas (1028 hymns). Source: sanskritweb.net proofread 7-bit ASCII
edition (2nd edition, Kotagiri 1896). Hymns are tagged `[BB-HHH]` (book–hymn).

Cited by the Revelations → Indian/Vedic tab: the 12-spoked / 360-spoke year-wheel
(RV 1.164), 720 sons, 7 metres, 7 horses of Sūrya, 27/28 nakṣatras, the Nāsadīya
creation hymn (10.129) and the Puruṣa Sūkta (10.90).
