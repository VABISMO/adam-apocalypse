## Completeness / number of volumes

*Oedipus Aegyptiacus* was published in **3 folio volumes** (Tomus I 1652,
Tomus II 1653, Tomus III 1654). Each volume is internally divided into two
parts (Pars I / Pars II), so the work is occasionally misdescribed as "4
volumes"; bibliographically it is **3 volumes**, and all three are present
here. Vol I's scan (~581 pages) contains both Pars I and Pars II of Tomus I
(the Mascardi 1652 Tomus primus runs [96], 424, [39] pages, matching this
scan). No fourth separate volume exists. All three PDFs were verified as
valid; sizes match the archive.org metadata exactly.
