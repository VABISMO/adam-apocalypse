# Shams al-Maʿārif al-Kubra — Aḥmad al-Būnī — library/al-boni

*Shams al-Maʿārif al-Kubrá wa-Laṭāʼif al-ʿAwārif* (شموس المعارف الكبرى ولطائف العوارف),
"The Great Sun of the Knowledges and Subtleties of the Familiars", by Aḥmad al-Būnī
(d. c. 1225 CE, 13th century), the celebrated Arabic grimoire of letter-, name-, and
seal-magic. A key cross-cultural parallel for the project's "alphabet from the sky"
thesis (celestial letters, divine names, talismanic correspondences).
