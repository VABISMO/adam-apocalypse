## Completeness

This is the complete 9-volume set of al-Futūḥāt al-Makkiyya (the Internet
Archive item contains exactly 9 "Image Container PDF" derivatives, one per
volume, fmakia1.pdf … fmakia9.pdf). All 9 files were downloaded and verified as
valid PDFs; sizes match the archive.org metadata exactly. The work is an Arabic
image-scan (no OCR layer), which is the appropriate complete form for this
manuscript-style edition.
