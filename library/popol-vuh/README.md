# library/popol-vuh — The Popol Vuh (Spence, 1908)

The **Popol Vuh** — the mythic and heroic sagas of the Kichés of Central America (the
Maya-Quiché creation myth and hero cycles), translated by Lewis Spence (1908). The
Mesoamerican corpus central to the project's Maya cross-cultural layer (RevelationsTab /
§15c Maya findings: the 260-day Tzolkin, the Long Count, the 13-numbers).
